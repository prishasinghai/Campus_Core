# 🎓 College Sync: WhatsApp & Email Student Planner

An AI-powered dashboard designed for first-year college students to aggregate, filter, and summarize chaotic group chat notifications and emails. It automatically extracts critical deadlines, isolates crucial event invites/links, and builds Google Calendar shortcuts.

## 🚀 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd whatsapp-student-planner
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the app:**
   ```bash
   streamlit run app.py
   ```

4. Open your browser to the URL displayed in the terminal (usually `http://localhost:8501`).
